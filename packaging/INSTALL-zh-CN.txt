Aggregate Audio v19 — Windows x64 测试版

适用：Windows 10 / 11 x64、64 位 ASIO 宿主（包括 FL Studio）。

安装：
1. 关闭使用 Aggregate Audio 的 DAW、设置面板和诊断工具。
2. 运行 AggregateAudio-v19-x64-Setup.exe，允许管理员权限。
3. 安装包内置微软 Visual C++ x64 运行库，不需要联网下载或安装开发工具。
4. 从开始菜单打开 Aggregate Audio，重新勾选这台电脑实际存在的输入、输出通道，保存设置。
5. 在 FL Studio 的音频设置里选择 Aggregate Audio，打开面板检查采样率和缓冲。

外置声卡应先安装其原厂 Windows 驱动。本安装包不包含声卡厂商的驱动。

建议首次使用 ASIO 主机缓冲 256 帧，设备 KS 缓冲也从 256 帧开始。
再根据电脑和声卡的实际稳定性调整。这只是测试起点，并不保证最低物理延迟。
请测试正常播放、监听，以及在声卡原厂面板改变缓冲后能否自动恢复。
设备恢复使用标准 ASIO reset 请求，是否接受由 DAW 决定。

安装包不会携带原电脑的通道选择、设备 ID 或音频配置。
设置保存在当前用户的 %LOCALAPPDATA%\AggregateASIO\settings.ini。
卸载：Windows“设置 → 应用”中卸载 Aggregate Audio。卸载会保留个人设置。
微软运行库是共享组件，不随本软件卸载。

本版包含紧凑高 DPI 面板、Settings 运行日志、设备去重、单窗口面板、
ASIO 运行时的通知区域图标、设备变化/流停滞自动恢复。虚拟通道功能已移除。
v12 修正首次打开面板时日志覆盖设备页的问题，并在首次显示前完成 DPI 布局。
后台设备刷新会保留当前浏览位置、选中通道及设备组折叠状态。
v15 将设备列表横向、纵向及日志页滚动条统一为浅色轨道、圆角滑块。
支持滑块拖动、轨道翻页、箭头、滚轮和键盘导航，并随 DPI 调整样式。
v16 将 ASIO 注册描述与 COM 显示名统一为 Aggregate Audio，升级会覆盖旧描述。
重新验证日志隐藏、后台追加日志、设备刷新、窗口缩放与页面切换，避免日志叠到设备页。
v17 增加设备占用保护：勾选、保存、自动检测和 ASIO 打开时会检查 KS 引脚占用。
遇到占用会弹窗提示“设备被占用，请释放后再试”，并停止继续尝试格式或缓冲档位。
普通 KS 引脚不再盲目请求 WaveRT 缓冲，也不再为此重复关闭、打开同一引脚。
自动检测前请关闭 DAW 并释放设备。此保护不能拦截声卡驱动自身的内核错误；
本次黑屏重启的 Windows 崩溃报告指向 usbaudio2.sys，尚不能确认占用是唯一触发条件。
v18 修正 E2x2 OTG 无法连接的回归：驱动不提供全局实例数属性时，继续读取局部实例数，
不再把 0x80070490 当作打开设备失败。只有已报告的实例容量已满时才判定占用，
允许支持多实例且仍有剩余容量的引脚正常连接；真正占用时仍会停止重试并提示用户。
v19 优先使用声卡驱动协商返回的准确格式，修正 Donner 等声卡的 24 位有效数据 / 32 位容器连接失败。
支持 20 位、8 位 PCM 和旧驱动格式回退，占用保护保持有效。KS 错误码移到提示开头，避免被宿主截断。
设备组内通道按名称字母与数字大小排列，同一组声道相邻，刷新和排序仍按原声道 ID 保留勾选。

反作弊相关：
Aggregate Audio 是由 DAW 正常加载的用户态 ASIO DLL，调用已有声卡驱动的 KS 接口。
本安装包没有 .sys 内核驱动，不注册驱动服务，不注入游戏进程，不修改游戏内存，
也不改变安全启动、驱动签名策略或反作弊设置。
按目前实现通常不会影响游戏反作弊，但未对具体游戏或反作弊产品进行兼容性验证。
第一次测试游戏时可先关闭 DAW。并行使用 DAW 可能导致声卡占用或游戏音频冲突。

本软件和安装包尚未进行代码签名。Windows 可能提示未知发布者或 SmartScreen；
这类提示不代表反作弊检测结果。请只使用可信来源提供的安装包。
